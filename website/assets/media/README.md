# Triumph's own photos and videos

Put Triumph's real photos and videos in this folder, then point to them in `assets/js/config.js`
(for example `video: "/assets/media/warehouse.mp4"`). Until then the site uses free Pexels stock footage.

Tips: short clips (10–30 s), 1280–1920 px wide, no sound, under about 8 MB each. Photos about 1600 px wide, JPG.
